# 每日复盘

入口：顶部「每日复盘」，与图表、板块雷达、市场情绪、条件扫描平级。手机上使用顶部工作区下拉菜单。

## 日常使用

1. 选择 A 股或美股；两个市场各自保存纪律、每日记录和每周总结。
2. 选择日期。A 股默认北京时间日期，美股默认美东日期；可以补录历史日期。
3. 填写当天市场与状态，选择有交易或观察日。
4. 仅勾选当天**违反**的交易纪律，并写下原因、心得和下次具体改进。
5. 添加关联股票，每只股票可以单独写备注。支持带入当前图表标的，也能从关联标的打开图表。
6. 点击「保存当日复盘」，保存到 NAS。

草稿暂存在当前浏览器。切换日期、市场、页面以及刷新时可以继续填写；只有点击保存后，记录才会写入 NAS 并计入统计。不要把草稿提示误认为已保存。

## 纪律管理

提供六条可修改的初始纪律。可随时添加、改名、停用或重新启用，每个市场最多 100 条。旧记录保存纪律名称快照；改名或停用不会改掉历史复盘。停用的历史违规仍可保留，不能在新日期新增勾选。

## 每周总结

周一至周日为一周，统计已保存复盘天数、有交易天数、未记录违规天数和出现违规天数。未填写的日期不参与统计；同一条纪律每天最多计一次。违规排行同时展示上周次数和上周样本天数。

可以设置一条本周重点纪律、具体行动和总结。下一周可点击「沿用上周重点与行动」，继续练习同一条纪律。

## 历史与导出

「历史回看」按月列出记录，点击日期可重新编辑。「导出记录」下载当前市场全部已保存纪律、每日记录和每周总结的 JSON 文件，不包含未保存草稿。

多页面同时修改同一条记录时，系统拒绝旧版本覆盖；先保留需要的草稿，再使用「载入已保存版本」核对。

## 数据与验证

数据保存在现有 `market.sqlite3` 的 `review_rules`、`review_days`、`review_weeks` 表中，兼容已有数据库。接口位于 `/api/review/`，HTTPS 图表入口通过原有登录和防跨站保护访问同一数据。

验收覆盖：两个市场隔离、纪律生命周期及历史快照、每日和每周版本冲突、跨周统计、关联代码校验、持久化、导出；浏览器覆盖保存/刷新、草稿恢复、断线重试、保存期间切换编辑、跨标签页冲突、每周重点延续、深浅主题和手机布局。
