# 周期切换后的视图适配

- 初次打开、切换股票/周期/交易时段以及返回实时后，显示近期适量 K 线，而不是将整个缓存 fitContent 到一屏。
- 按图表绘图区宽度，约每 8 像素安排一根 K 线，目标范围限制为 40–160 根，并保留少量右侧空间；缓存不足时显示现有数据。
- 同时恢复主副图右侧价格轴的自动缩放与正常模式，上下各留约 12% 边距，避免继承上一周期手动拉开的范围。
- 工具栏“重置视图”用当前已加载数据恢复默认比例，不请求行情。要回到最新行情仍使用“实时”。
- 日期定位保留目标日期窗口，并恢复价格轴自适应。向左补载和普通实时数据更新不反复重置手动视图。
- 多图初始化/程序重置不广播时间范围；用户拖动后的时间同步保留，并避免同步回弹。空图和正在加载新周期的图不参与同步。同周期刷新不重置手动视图，也不会永久关闭同步。
- 切换后的旧 WebSocket 消息被忽略。盘口密集线仅作为价格标记，不再强行扩大 K 线自动价格范围。

验证：时间窗口计算与主副价格轴恢复单元测试；浏览器实际竖向拉动价格轴后切换 5m/15m/60m/日/周/月、时间缩放后重置、不同价格区间和慢加载双图、同周期刷新后手动双图同步。未修改 OpenD、交易或 OpenClaw。
