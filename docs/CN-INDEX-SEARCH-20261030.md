# A 股指数搜索修复（2026-10-30）

- 原因：旧目录只请求默认 STOCK，并过滤掉指数；前端将六位数字直接猜成个股交易所。
- 使用官方 OpenD `get_stock_basicinfo(market, stock_type='IDX')`，分别缓存上海和深圳指数，独立七天更新与五分钟失败冷却；离线仍可查本地缓存。
- 搜索支持指数中文名、简称片段、六位代码和完整代码。`000001` 同时展示 SH.000001 上证指数（指数）和 SZ.000001 平安银行（股票）；回车采用当前高亮的结果，加载期间不猜交易所。完整 SH/SZ 代码允许直接查看。
- 查看不会自动加入自选；加号才加入当前组。没有数据权限时保留真实权限提示，不替换模拟数据。

真实 NAS/OpenD 验证：上海 IDX 321 项、深圳 IDX 400 项；SH.000001 的 K_15M 历史查询返回成功（20 根）。目录包含上证指数、沪深300、深证成指、创业板指。

验证：125 项 Python 测试、TypeScript 检查与前端构建通过；Edge 验证裸代码不会误跳、指数及股票分别可选、完整代码直达及不自动收藏。部署前确认没有启用中的本地策略、待跟进止损或未确认订单操作；行情容器更新会使交易台回到锁定状态。
