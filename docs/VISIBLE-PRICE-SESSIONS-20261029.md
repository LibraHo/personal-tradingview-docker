# 纵向可见极值与扩展时段

“区间高低”以主图当前可见价格范围为界，从画面内 K 线的真实最高价影线端点、最低价影线端点中分别选取最高与最低。只露出部分影线、端点已在画面外时，不把价格轴边缘当作顶点；该方向没有可见端点就不显示标签。纵向拖动或缩放价格轴会立即重算，横向不在画面内的 K 线也不参与。

美股顶部增加“扩展时段”按钮：关闭仅保留常规时段；重新开启恢复上次的“盘前＋常规＋盘后”或“24H 全时段”。右侧下拉仍可明确选择范围，沿用工作区保存。

- 常规：默认深色背景。
- 盘前：浅蓝背景。
- 盘后：浅金背景。
- 隔夜：浅紫背景，仅 24H 模式包含。

背景覆盖主图及指标副图，跟随 K 线数据的实际时段分类，不凭本机时区猜测。日、周、月线及 A 股不显示美股扩展时段背景。切换范围沿用既有 OpenD 订阅与 SQLite 缓存逻辑。

验证包括：纵向裁剪、独立高低端点、边界值、倒置价格轴、仅纵向缩放时重算、无有效顶点时隐藏；时段背景分段、裁剪、置于 K 线下层、常规时段排除；浏览器实际拖动价格轴和扩展时段开关。
