# 日线、周线、月线

周期栏支持 1m、5m、15m、30m、60m、日线、周线、月线。API 周期分别为 `1d`、`1w`、`1mo`，对应 OpenD 原生 `K_DAY`、`K_WEEK`、`K_MON`，不在网页拼接假周线或月线。

日 / 周 / 月线固定使用常规时段数据及 `Session.NONE`，不套用分钟线 24H 筛选；切回分钟线保留原来的时段设置。图表、内置 / Python 指标、颜色、画线均可使用新周期。已有「全部周期」指标自动纳入新周期，显式选择部分周期的指标保留原设置。自动交易策略仍只支持原有分钟周期，进入策略编辑器时从长周期回退到 60m，不表示已经支持周 / 月收线自动交易。

首次历史范围可配置：

- `WEEKLY_HISTORY_DAYS=1825`：约五年周线。
- `MONTHLY_HISTORY_DAYS=3650`：约十年月线，便于长周期指标预热。
- `LONG_CACHE_RETENTION_DAYS=3650`：周 / 月线缓存保留，至少覆盖默认历史请求。分钟线与日线保留规则不变。

历史缓存、较早数据加载、重新连接补齐、推送周期识别均覆盖新周期；推送按股票及 K 线类型分开处理。当前周 / 月柱会随交易更新，不代表该周期已经收盘。

2026-10-27 真实 NAS 核验：SNDK 周线 90 根，2025-02-10 起；月线 21 根，2025-02-01 起。原生历史查询及两个周期实时订阅均成功。起始日期取决于上市时间、OpenD 可提供数据及权限，选择更长请求范围不保证存在更早记录。

测试：新增周 / 月周期验证、常规时段限制、推送类型、历史范围与缓存清理保护测试；102 项后端测试通过。
