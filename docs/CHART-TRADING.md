# 图内快捷交易

入口为交易服务的 HTTPS `/chart`（本机 NAS 为 `https://192.168.101.103:8443/chart`）。原 HTTP 看盘页点击“看盘交易”会转到该入口，登录平台后在图表下方展开交易面板。图表与交易在同一页面，不再弹出独立窗口。

- 实盘依旧必须手动输入交易密码解锁；原来的后端权限、订单预览、幂等提交、额度及持仓校验保持生效。
- 面板显示固定交易股票；切换观察图表不会悄悄改变正在填写的订单。点击图表交易按钮或“带入当前图表”才切换交易股票。切换股票清空价格、预览并关闭快捷模式。
- 选择账户，设置数量、价格、订单类型和交易时段；“买入”“全部平仓”采用这些设置。默认先预览；用户主动开启快捷模式后直接提交。
- “成本 -2.5% 止损”对当前可卖数量设置止损市价单，RTH / GTC。自定义命名方案沿用现有编辑器，可设置股数、止损比例、类型及美元容限；命名买入方案固定限价 RTH / DAY，使用用户填写的买入限价。
- 已有止损占用数量、订单结果未核对、持仓变化等仍由后端阻止冲突提交。不会自动撤销用户已有保护单。
- 关闭面板、隐藏页面或切换账户后，重新启用快捷模式。平台密码与券商交易密码仍分开；不向行情容器转发任何密码、Cookie 或 CSRF 标记。

HTTPS 交易服务仅转发行情接口白名单到 `MARKET_INTERNAL_URL`，合并部署时为 `http://127.0.0.1:8000`，分开部署默认 `http://market:8000`；外部浏览器仅使用 HTTPS/WSS。同源会话保护 HTTP 与 WebSocket 行情接口，所有写请求校验 CSRF，保持禁止页面嵌入的策略。部署服务更新会要求重新登录和解锁，不会自动恢复交易授权。

## 缓存与权限

K 线存储在 NAS 挂载的 SQLite 中，不是公司电脑浏览器。同步进度也持久化；重启后从最新缓存日期补齐到当前日期，带两天重叠用于修正末尾 K 线。扩大历史窗口、向左加载旧数据仍可能请求历史接口；不保证检测缓存内部所有缺口。

默认分钟线保留 30 天，日线保留 1825 天，可用配置调整。“数据与缓存”显示当前实际条数、占用及日期范围。盘口筛选设置存 NAS，盘口行情本身仍为短期内存缓存。

A 股无权限时保留历史缓存并显示明确状态，中文名称单独缓存，不将缓存冒充最新行情。券商授权需在 OpenD 核查：[官方行情权限说明](https://openapi.moomoo.com/moomoo-api-doc/en/intro/authority.html)。App 权限不能据此推断为 API 权限。

## MACD

柱值非负使用绿色；负值使用红色。同侧绝对值缩小时使用浅绿 `#B2DFDB` 或浅红 `#FFCDD2`；增长、相等或跨过零轴使用深绿 `#26A69A`、深红 `#FF5252`。计算公式不变。

## 页面布局

美股和 A 股共用顶部工具区，交易快捷按钮和交易面板位于 K 线下方；A 股底部显示仅看盘提示。盘口挂单线的开关和筛选参数在右上角“设置”内，作用于当前选中图表的股票；关闭设置窗口不会停止已启用的盘口更新。多图显示同一股票时参数同步。
