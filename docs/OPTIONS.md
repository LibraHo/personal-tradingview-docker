# 美股单腿期权与快捷键

入口：HTTPS 看盘页图表下方「期权」，或交易台上方「期权」标签。账户与手动解锁按钮在表单上方。平台登录和实盘手动解锁沿用现有流程。

1. 填写 `US.SNDK` 等标的，读取到期日。
2. 先选到期日，再点「最近 Call / Put」，按正股快照选该日期最近行权价；同距取较低行权价。可展开手动选择或从持仓选择，绝不根据期权本身价格挑行权价。
3. 快捷选约会把买入卖一价 / 卖出买一价填入限价；必须检查快照时间，限价不会自动追价。支持买一 / 中间价 / 卖一及 $0.01 调整。选 1/4、1/3、半仓或全仓：买入按美元现金计算，预留费用、受单笔上限和券商现金购买能力约束；卖出按可卖多头张数向下取整。不足一张不会凑单，固定张数按钮放在折叠区。
4. 点击买入、卖出、全部平仓；需要卖一半时在卖出方向选半仓。默认先预览；主动开启快捷模式后直接提交。更换合约或刷新快照会关闭快捷模式并清空限价，更换账户会重置期权选择。

默认张数按钮 1、2、5，可修改并保存到 NAS。与股票的股数按钮分开保存，不覆写股票止损方案。

后端从 OpenD 获取期权信息，识别 `option_valid`，从正股基本信息确认股票 / ETF 标的，并用期权链确认 `option_standard_type=STANDARD`；校验 `option_contract_size`、`option_contract_multiplier`、`lot_size` 均为 100，以及到期日未过期。金额按 `权利金 × 张数 × 合约乘数` 计入原有单笔金额上限，不含费用。缺失乘数时拒绝，绝不默认猜测 100。期权实际最小报价步长、账户等级、现金购买能力、券商受理仍由 OpenD / 券商校验。

当前仅开放标准 100 股交割的股票和 ETF 单腿期权，RTH / DAY 限价。卖出必须有足够的多头可卖张数；禁止卖空。实盘开放卖出已有多头的 STOP / STOP_LIMIT，价格固定两位小数，RTH / DAY。可填写固定止损价与卖出限价容限，也可按买入限价 / 持仓成本快捷填写比例。买入附带止损使用 NAS 成交后补挂，约每 5 秒检查（不是券商原生 bracket），存在未保护时间；锁定、退出、解锁到期或重启后暂停跟进，结果不明不重发。模拟账户不支持止损。暂不开放组合单、指数期权、调整合约和自动行权。股票 GTC 止损方案不直接套到期权上。期权持仓行的比例卖出按整张向下取整。

期权链是静态信息，不代表实时行情权限。到期日与按到期日查询的合约链缓存五分钟，最多 32 组；只为选中的合约读取快照，不订阅整个期权链。快照显示美东时间，不承诺可执行价格。首次接口超时会显示错误，可手动重试，无订单自动重发。

接口（均在原 HTTPS 认证边界内）：

- `GET /api/trade/options?code=US.SNDK`：到期日。
- `GET /api/trade/options?code=US.SNDK&expiry=YYYY-MM-DD`：该到期日静态合约链。
- `GET /api/trade/quote?code=具体合约代码`：选中合约快照及乘数。
- `GET /api/trade/options/nearest?code=...&expiry=...&direction=CALL`：最近标准合约及正股快照依据。
- `GET /api/trade/options/size?acc_id=...&env=...&code=...&side=BUY&fraction=1/4&price=...`：只读测算；不解锁、不提交订单。
- 订单沿用 `preview` → `commit`，幂等流水、解锁有效期及结果未知不重发规则不变。
- `GET/PUT /api/trade/presets` 增加 `option_quantities`，兼容旧设置。
