# 条件变化与六脉取值修正

## 边界定义

| API 操作 | 前一根 | 当前根 | 阈值 3 的示例 |
|---|---|---|---|
| cross_above | ≤ 阈值 | > 阈值 | 2→4、3→4；不含 2→3 |
| cross_below | ≥ 阈值 | < 阈值 | 4→2、3→2；不含 4→3 |
| reach | < 阈值 | ≥ 阈值 | 2→3、2→4 |
| fall | > 阈值 | ≤ 阈值 | 4→3、4→2 |
| enter_eq | ≠ 阈值 | = 阈值 | 2→3、4→3；不含 3→3 |
| rise_eq | < 阈值 | = 阈值 | 2→3；不含 2→4、4→3 |
| fall_eq | > 阈值 | = 阈值 | 4→3；不含 4→2、2→3 |

上述比较每根均与各自对应的右侧值比较，也支持指标间比较。缺少前一根输入不能视为命中。gt/gte/lt/lte/eq 为持续状态判断，不隐含变化。

新增“刚变三绿（恰好三个）”与“刚达到至少三绿”预设。每条 rule 支持可选 name（最多100字），随方案保存、复制以及监控固定版本持久化。网页可命名、添加、复制条件。组合精确方向也可用历史偏移条件 AND 当前条件，例如上一根绿灯=5且本根绿灯=3。

比较数值有显式标签；历史偏移与倍数收进独立区域，有非零偏移提示。摘要显示六脉状态允许的0～6集合，结果显示任务实际规则、左右值、变化前值、取值日期和条件名称。checks 新增 name/left_time/right_time，不改变旧字段。
