# 腾讯 A 股离线日线

`app.tencent_archive:factory` 可读取 `a-share-indicator-backtest/fetch.py` 生成的 `.data` 目录。向服务进程设置 `TENCENT_ARCHIVE_DIR` 为归档目录的绝对路径。Docker 部署时将目录以只读卷挂载，并使用容器内的路径。

例如，以下 `MARKET_DATA_ROUTES` 配置将 A 股历史行情指向归档，选用不复权，关闭该市场的实时 K 线推送。其他能力按已有路由配置执行。

```json
{"CN":{"history":"app.tencent_archive:factory","live":"disabled","adjustment":"none"}}
```

支持归档内沪深主板、创业板、科创板样本股票的常规日线。归档按上海交易日期记录，不含实时刷新、分钟线、报价快照、成交额和完整交易日历。图表显示该股票归档的最后交易日。离线文件无法证明行情已更新到当前交易日。归档文件或样本缺失时会显示原因。

每个文件的 `raw` 键包含按时间分段下载的日线。行的前六项依次为日期、开盘、收盘、最高、最低、成交量。适配器校验重叠交易日的值并合并，同日值冲突时报告异常。主板和创业板的原始量以手计，转换为股时乘 100。已核对的科创板样本以股计，直接保留。指数的量纲未核实，接口仅接受上述股票板块。

复权设置支持 `none`。现有采集脚本在腾讯缺少 `qfqday` 时会回退到 `day`，同时不同下载区间可能使用不同的调整基准，因此此适配器只读取 `raw`。

2026-11-16 归档中，SH.600000 的开、高、低、收分别为 10.45、10.78、10.39、10.78 元，原始量 964,157 手，接口返回 96,415,700 股。SH.688006 同日原始量为 6,301,772 股。此前 2026-11-13 的独立搜狐归档显示该股成交 64,459 手，对应腾讯的 6,445,920 股，差异来自按手取整。这里的日期指数据本身的交易日期。
