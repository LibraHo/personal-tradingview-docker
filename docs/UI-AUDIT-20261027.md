# 2026-10-27 界面审计与调整

依据本次 Edge 截图审计，沿用 Product Design Audit 技能。桌面 1500×1100、窄屏 390×844；看盘使用真实 NAS 缓存 K 线，交易页面用完全隔离的账户响应检查交互，不输入密码、不提交券商订单。

## 逐步发现与修正

1. 看盘入口：行情保持主体，自选分组横向，交易在图下。此前画线只有符号按钮，含义不明显；改成有文字的工具栏，增加选中状态、取消、Esc、画线管理和撤销。保留 A 股 / 美股工作区。
2. 交易台：此前账户与解锁在期权表单之后，股票快捷卡、期权表单和股票表单同时展开。改成账户条在最前，股票 / 期权标签切换，一次显示一个下单区。桌面上期权仓位 / 限价和止损并列，说明与固定张数折叠，移除被 CSP 拦截的外部 Google 字体请求，使用本机字体，持仓 / 订单 / 流水统一放在下方。直接下单模式明确标为「快捷模式 · 直接提交」。
3. 期权任务：先选择到期日，再最近 Call / Put；按正股快照匹配行权价，显示依据与时间。1/4、1/3、半仓、全仓按钮突出；买入按美元现金、卖出按可卖张数，展示向下取整结果与预算。限价变化后重新测算，等待测算期间禁止提交。零值 / 负值止损不能静默变成普通买单。
4. 图表编辑：新增斐波那契 0 / 23.6 / 38.2 / 50 / 61.8 / 78.6 / 100% 回撤；0% 在第二锚点、100% 在第一锚点。主图分别单击两点，不使用双击。管理器可以修改价格、颜色、反转和删除，撤销最近一次编辑；切换周期清除未完成绘制及撤销状态，避免把上一周期画线写入当前周期。
5. 指标编辑：颜色、适用图和周期分区折叠，减少同屏按钮。每条线可选色，MACD 四种柱色、成交量涨跌色单独控制，Python 输出线支持指定线名配色。颜色和图形进入既有工作区保存流程，指标模板自然包含 colors 字段。

## 验证

- 98 项后端测试通过，包含仓位测算、1/3 整除边界、期权两位小数、固定触发价、分批成交止损及不会重复补挂。
- 前端构建、MACD / 成交量默认和自定义配色、斐波那契公式检查通过。
- 浏览器完成最近 Call / Put、价格与仓位联动、无效止损阻止提交、买入附带保护预览、已有持仓止损预览、1/3 可卖张数卖出预览；3 次隔离预览、0 次提交。
- 画线编辑、保存后刷新恢复、删除与撤销、跨周期隔离、指标颜色刷新恢复通过。设置写入被隔离，不改动用户实际工作区。
- 桌面与 390px 页面未发现横向溢出，无页面运行错误。颜色选择器和主要按钮有可读标签及键盘焦点样式。
