# 指标查找与添加

指标管理的原生下拉框改为搜索输入框与可见结果列表。中文名称、英文简称不区分大小写；为 MACD SHORT MAI、六脉主图/副图等补充别名。多个空格分隔的关键词须同时匹配。

默认只显示快捷入口与搜索；输入关键词或点击“浏览全部”才展开结果。已添加指标默认只显示名称、开关、位置标签、设置与删除，点击设置才展开参数、配色和范围。自定义编辑器与模板也默认收起。

结果标注默认主图/副图位置；选中项高亮，下方显示完整名称。无结果时禁用添加，避免误加之前选中的指标。固定位置指标不能改为另一位置。

MACD突破、六脉主图上下车、六脉副图共振提供快捷添加入口。添加后显示当前市场及位置反馈；原有参数、配色、适用图/周期设置和工作区保存路径沿用。

已添加卡片显示完整名称，避免只出现 SIXPULSE_SIGNAL 等内部代号。

验证：中英文搜索/别名及空结果测试；浏览器中的搜索→选中→添加、快捷添加、空结果保护、图表绘制、模拟存储刷新恢复、折叠参数编辑保留、390px 窄屏布局。生产 NAS 最近的工作区保存请求返回 200；用户进一步明确主要问题是界面杂乱。
