# 两小时与四小时 K 线（2026-11-04）

周期栏新增「2小时」「4小时」（API：`120m`、`240m`）。周期切换、图表布局保存、内置/Python指标、指标周期范围、各周期画线和绘图 API 同步支持。旧配置的全部八周期指标自动包含新周期，明确选定部分周期的设置保留。

## 数据规则

- 美股：由真实 OpenD `K_60M` 合成为 2h/4h，不使用模拟数据。官方历史接口协议注明 `session` 仅支持60分钟及以下，不能仅凭 K_120M/K_240M 返回成功就认定全时段正确。按美东时区的盘前04:00、常规09:30、盘后16:00、隔夜20:00分别对齐；常规2h从09:30/11:30/13:30/15:30开始，4h从09:30/13:30开始；时段末尾允许不足完整周期，不跨时段合并。夏令时使用 America/New_York 自动处理。默认加载最多30天（受配置缓存保留期约束）。
- A股2h：OpenD 原生 `K_120M`，上午、下午各一根，遵循源数据时间标签。
- A股4h：映射 OpenD 原生 `K_DAY`，一天一根，OHLC和量额与日线一致，午休不计入交易时间。实测当前NAS的原生 K_240M 与 K_120M 都返回上午下午两根，不能拿它当一天四小时。默认历史长度和保留期与日线一致，工作区仍保存为240m，画线可独立设置。

## 实时与缓存

真实60m源与合成周期均保存到SQLite；每次推送按源时间覆盖，再从缓存重新计算受影响的2h/4h，避免累加同根推送的成交量。断线沿用既有重连和历史重叠校正机制。订阅按实际源类型共享：美股60m/2h/4h共用同一源订阅（相同时段范围）；A股4h/日线共用日线订阅；退出某图不会退订其他仍在使用的源。

自动交易策略的收线周期仍保持原来的1/5/15/30/60分钟；从新图周期打开策略编辑器时默认60m，需要在策略内明确选择，未增加自动下单行为。
