## 终端输入回归修复

首次真实网页登录返回“账号密码不齐全”。此前隔离检查仅确认账号、密码提示切换，不能证明 OpenD 收到了非空输入，因此未发现此缺陷。

根因是 `pty.openpty()` 的默认终端尺寸为 0×0，OpenD 10.11.7108 的原生行编辑器丢弃输入字符但接受换行。每次创建 PTY 后、启动子进程前设置为 32 行、1024 列，覆盖首次启动和重新登录。宽度容纳接口允许的 512 字节输入。额外区分“不完整输入”和网络异常，支持错误原因跨数据包到达。

修复验证：

- 48 项登录相关 Python 测试通过，包含错误消息在每个 UTF-8 分包位置的分类测试。
- 在隔离真实 OpenD 容器中，禁用网络、不挂载真实用户 home，仅使用固定测试账号和密码。修复前收到“账号密码不齐全”；修复后进入实际登录流程，并得到预期的离线网络错误，证明非空凭据已传入。
- 原生密码回显为星号，适配器响应和容器日志未暴露固定测试密码。调试输出仅用于隔离测试，生产文件不包含原始终端输出。
- 只替换既有 OpenD 容器内挂载的适配器文件并重启 OpenD；Market 无需重建，未增加常驻容器。更新前确认运行策略、待处理止损、未决提交均为零。
- 生产适配器启动正常，版本 10.11.7108，进入等待账号阶段。真实账号登录、短信或图形验证仍需用户亲自完成，不以离线测试替代。
