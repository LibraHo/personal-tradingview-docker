# 自定义策略（第一版）

入口：HTTPS 看盘页 `/chart` → K 线下方“自定义策略”。平台登录仍使用原来的密码；指标代码没有交易权限，不接入 AI 服务。

## 第一次使用

1. 新建策略，选择股票、1/5/15/30/60 分钟及计算行情时段。
2. 添加内置指标，或点“引用当前图表指标”复制图表中的内置/Python 指标及参数。保存后为独立快照，图表改动不自动改变策略。
3. 买入、卖出分别添加条件，组合方式为全部满足或任一满足。条件可引用指标输出、OHLCV 或常数。
4. 点“试算最近收线 · 不下单”，核对输出线、数值、信号及语法错误。这里检查最近完成 K 线，不是回测。
5. 保存策略，点“启动监控”。默认只记录信号，后台约 15 秒一轮，实际耗时随任务顺延。关闭网页/编辑器后仍监控；用“暂停监控”停止。
6. 点“记录”查看检查、信号、跳过、订单受理或错误。订单受理不是成交；实际成交仍在原交易面板或 moomoo 核对。

## 例：60 分钟 VWAP 上穿 BBI 买入

默认编辑器已有 VWAP 和 BBI。

- 周期：60m；计算时段按自己的图表选择。
- VWAP 参数：按时段重置、按交易日重置或不重置。默认按时段，不同选择会得到不同信号。
- BBI 参数：3,6,12,24，可改。
- 买入：`vwap:main` 上穿 `bbi:main`。
- 卖出：可以独立定义，例如 `vwap:main` 下穿 `bbi:main`；删除全部卖出条件则只产生买入信号。
- 默认禁止跨交易时段判断交叉，避免 VWAP 重置跳变制造假信号；确实需要时才开启。

## 自定义 Python 指标

既可以引用图表中已有 Python 指标，也可以直接增加 PYTHON 指标源。沿用现有受限 Python 运行器：math/statistics 白名单、无文件/网络/下单访问，独立进程、3 秒超时，Linux 下 128MiB/2 秒 CPU 限额。

```python
fast = EMA(C, PARAMS["fast"])
slow = EMA(C, PARAMS["slow"])
result = {
    "买入信号": [int(a > b) for a, b in zip(fast, slow)],
    "卖出信号": [int(a < b) for a, b in zip(fast, slow)],
    "差值": fast - slow,
}
```

参数：`{"fast":12,"slow":26}`。

假设源 ID 是 `custom`，可配置 `custom:买入信号` 上穿数字 `0` 时买入、`custom:卖出信号` 上穿数字 `0` 时卖出。输出为 1 持续多个周期时，上穿条件只在从 0 到 1 的那根成立。大于/小于条件则每根满足时都会产生信号，需配合空仓限制及执行次数。

输出线数值为 None 时不触发。SMA/BBI 等预热不够也不触发；EMA 的初值依赖缓存起点，当前使用最多最近 30 天、5000 根缓存窗口，不保证与载入更长历史的其他软件逐点完全一致。Python 自定义预热规则由作者定义。

## 自动执行与限制

- 先启动信号监控，再点击“启用自动执行…”，选择账户并确认后台执行。实盘需先在原交易面板手动解锁。
- 最长授权 10 分钟，且不超过当前实盘解锁的剩余时间；默认每次授权最多 1 次，可以配置 1–10 次。
- 第一版自动下单只在美股常规时段 RTH；全时段可用于信号监控。要求最新快照 15 秒内，信号收线结束 90 秒内。
- 只提交限价 DAY 单，按最新快照加/减配置偏移，且限价和现价都不能超过距信号收盘价的偏离上限；没有成交保证。
- 买入固定整股，默认已有持仓不再买；卖出按可卖持仓比例取整；不做空。已有未结束订单则本次停止自动执行，避免与手工订单/止损冲突；不会自动撤单。
- 可选买入成交后止损，复用已有 NAS 跟进机制，仅实盘/RTH。该机制不是原生附加单，成交后存在未保护时间；锁定和解锁到期会暂停跟进，需要核对处理。
- 关闭网页不取消已授权的后台执行。暂停监控、关闭自动执行、锁定交易、退出平台、到期、配置修改、服务重启均解除策略执行授权。券商已接受的订单继续有效。
- 重启后恢复信号监控，不自动恢复实盘授权。启动时以当前 K 线建立基线，不执行历史信号；断线跨过多根 K 线时跳过，不补单。最后不足一个完整周期的时段 K 线采用保守的完整周期结束时间，可能延后。
- 买卖同时满足时，本根不执行。提交前持久化处理游标；结果待核对时停止，不盲目重发，沿用原操作流水核对机制。取消授权会在最终提交前再次校验；已经送达券商的订单不能由此撤回。
- 第一版每条策略一个股票、一个周期，最多保存 16 条、同时运行 8 条，每条最多 8 个指标源、每个方向最多 8 个条件。支持内置和 Python 指标；简易公式指标、跨周期组合、嵌套条件树、回测和无人值守长期交易授权尚未提供。

## 存储与接口

配置/检查游标/最近 1000 条全局事件：`/trade-data/strategies.sqlite3`（沿用 trade-data 持久卷）。自动执行授权只在内存，不存交易密码。

行情容器 `/api/strategy/evaluate` 校验配置并计算，只读；活动监控持有 75 秒订阅租约，后台轮询续约，多任务/图表共享同股票周期订阅。停止后租约到期、遵守 OpenD 至少一分钟订阅要求后退订。宽时段订阅可复用于窄时段，窄时段按会话过滤。

HTTPS 交易接口：GET `/api/trade/strategies`、`/events?id=...`；POST `/save`、`/test`、`/start`、`/delete`、`/arm`、`/disarm`。沿用平台会话、同源和 CSRF 校验。执行通过原 TradeEngine 串行预览/提交，复用账户权限、资金/持仓、限额、价格和幂等操作流水。

后端测试覆盖收线、交叉、跨时段重置、预热、Python 输出、游标持久化、订阅复用、只监控不下单、未解锁拒绝、断线跳过、信号冲突、重复执行、过期快照和结果不明不重试。

Edge 隔离测试用真实 NAS 的 SNDK 60m K 线完成 VWAP/BBI 与 Python 买入信号试算，检查保存、启动、实盘未解锁按钮禁用、模拟授权和窄屏布局。交易 API 为隔离测试接口，没有向用户账户提交订单；盘中真实成交仍需用户自行验收。
