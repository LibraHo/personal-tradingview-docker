# A 股中文名称搜索

切换左侧“A 股”，在底部输入框输入中文名称、部分名称或代码，例如“茅台”“长电”“600519”。结果同时显示中文名称及 `SH.` / `SZ.` 代码，点击结果加入当前分组并打开图表。也可以用上下方向键选择，回车确认，Esc 收起。

输入完整六位代码可直接回车添加。中文输入法组合输入期间，回车只确认输入法，不触发添加。美股继续按代码添加。

名称来自现有 OpenD 的股票静态资料，无需订阅实时行情。首次搜索时按需获取沪深股票目录，缓存到 NAS SQLite 的 `symbol_names`；目录默认七天后才重新查询，重启后继续复用。首次建立目录可能稍慢，界面会显示搜索中。查询失败保留已有缓存并短时冷却，避免每次输入都重试 OpenD。目录不可用时可继续直接输入代码，缓存结果可能不完整。

目前名称目录覆盖沪深 A 股股票，不包含北交所、B 股或基金名称目录；已有代码添加能力保持。搜索成功不代表具备该股票的实时行情权限。

名称搜索接口：`GET /api/symbols/search?market=CN&q=茅台&limit=12`。HTTPS 登录看盘页使用既有认证行情代理路径 `/api/market/symbols/search`。关键词最多 32 字，最多返回 20 项，不支持画线 Token 调用此接口。

官方接口依据：[获取静态数据](https://openapi.futunn.com/futu-api-doc/quote/get-static-info.html)，`get_stock_basicinfo` 省略 `code_list` 获取全市场股票基本信息；实际可用性已在本 NAS 的 moomoo OpenD 上核验。
