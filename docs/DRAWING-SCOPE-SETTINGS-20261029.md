# 画线周期、当前股票与统一设置

## 画线周期

水平线、趋势线、斐波那契都可在“画线管理 → 样式 → 周期显示”选择“仅当前周期”或“所有周期（当前股票）”。默认及旧画线均仅当前周期。

共享对象保留单一来源，不向其他周期复制。跨周期修改、删除和单个显隐同步生效；在另一周期限制为“仅当前周期”会移入当前周期。不同周期同名 id 不会相互覆盖。整体隐藏仍只隐藏当前图表。每个股票、存储周期、类型最多 100 个对象；超限拒绝，不裁剪其他共享对象。

OpenClaw 画线 API 的 POST/PATCH 支持 `timeframeScope: "current" | "all"`，详见 DRAWING-API.md。查询返回对象的 period 为存储周期，修改时使用该值。

## 当前查看股票

桌面顶栏显示当前股票名称、代码、活动图编号和周期。活动图标题有“当前图”标签。搜索只查看、未加入当前分组时，左侧显示临时查看卡片和加入本组按钮；不会自动收藏。多图切换时标识跟随当前图。

## 统一设置

右上角只保留一个“设置”入口，包含指标管理、盘口密集线、数据与缓存三个页签。缓存页保留 OpenClaw 接入入口；交易密码不迁入此面板。

- 指标按主图叠加和独立副图分组。每项都有绘制位置选项，可移动位置；添加内置或自定义指标时也可指定。EMA/MA/BBI/VWAP/BOLL 默认主图，MACD/RSI/ATR/DMI/成交量默认副图。旧的显式 pane 配置保留。
- 工具栏“挂档密集线”直接点击开关，不打开弹窗；关闭会清线并停止该功能的盘口轮询。最低金额、最低股数、每边数量、休市缓存开关集中在设置里，关闭状态也可编辑。设置按股票保存，同股多图同步。
- 设置关闭支持 Escape，并将焦点交回入口。各设置页不再叠加第二个弹窗。

验证覆盖共享对象增删改、切换周期、同 id 冲突、撤销、80 个共享对象后新建不丢数据、100 个源对象拒绝新增；主副图设置保存、盘口直接开关与停止轮询、同股多图同步、缓存嵌入与焦点恢复。
