# OpenClaw 画线 API 与同步

独立的 Bearer 凭证仅允许管理水平线、趋势线、斐波那契和整体显隐。HTTPS 入口用严格路径及方法白名单代理到行情服务，不转发交易会话，不接受画线凭证调用下单接口。凭证以 NAS 数据目录中的 600 文件持久化，已登录 HTTPS 用户可手动查看；Token 不写入前端包、日志或 GitHub。

复用 SQLite workspace，并在同一事务中维护 drawing_revision。外部 CRUD 使用 BEGIN IMMEDIATE 原子修改对象，保留自选、指标及其他画线；稳定 id 提供创建重试去重，If-Match 支持乐观并发校验。网页写入附带版本，冲突时保留数据库画线并回传给网页，避免旧整份设置抹掉 Agent 的更新。旧版无版本页面不能覆盖已有更新。

网页可见且无本地未保存编辑/拖动时，每 3 秒检查版本，只合并画线字段。网页隐藏或关闭时不轮询。保存串行化，跳过过期快照；网络失败时有界指数退避重试并提供手动按钮。

提供只依赖 Python 标准库的 OpenClaw 客户端及技能说明，支持只读挂载 Token 和 CA 证书；不自动改动 OpenClaw 自身部署。验证 CRUD、字段校验、重试去重、版本冲突、跨客户端同步、失败恢复，以及认证隔离和真实渲染；不操作真实交易账户。
