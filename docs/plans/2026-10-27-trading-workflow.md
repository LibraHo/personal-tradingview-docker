# 看盘与期权交易整理计划

目标：在同一看盘页完成比例选仓、最近行权价选约、限价与止损；整理重复入口并增加可保存的斐波那契画线。

采用现有 React / Lightweight Charts、FastAPI / SQLite，保持现有工作区数据兼容。不新增容器或重启 OpenD。

1. 先捕获现有看盘页和交易台截图。交易台使用隔离账户数据检查布局，不读取密码或提交订单。记录页面层级、重复操作、密度及键盘访问问题。
2. 新增只读期权仓位测算：1/4、1/3、1/2（也可整仓）；买入以美元现金与券商现金购买能力、手续费预留、单笔上限计算，卖出以可卖整张向下取整。预览和提交继续检查实际能力，不因行情变化悄悄增加张数。
3. 到期日由用户选择；用标的最新快照选择该到期日行权价最近的标准 Call 或 Put。同距取较低行权价；展示正股价格和时间，缺失行情拒绝猜测。限价支持买一、中间价、卖一与小幅调整。
4. 开放实盘期权已有多头的 STOP / STOP_LIMIT（RTH / DAY）；买入可明确授权成交后补挂止损，复用持久化跟进、分批成交及未知结果不重试规则。选填固定触发价，容限单独显示。模拟交易仍不提供止损。全部按美股期权两位小数处理。
5. 交易台先显示紧凑账户条，再以股票 / 期权标签切换单一下单区；避免同时铺开两套表单。持仓 / 订单 / 流水维持单一账本，高级说明折叠。看盘交易仍在图下。
6. 画线工具栏提供水平线、趋势线、斐波那契回撤，明确两点操作、取消、撤销、对象列表编辑删除。斐波那契独立存储，兼容旧工作区；主图外点击不绘图，切换股票 / 周期取消未完成对象。
7. 后端增加测算、精度、止损和跟进测试；前端验证最近合约、比例和限价联动，以及画线保存与恢复。完成桌面 / 窄屏截图复查、代码审查后备份并部署 NAS、同步 GitHub。

官方依据：OpenD 交易 FAQ 的美股期权类型表确认 STOP / STOP_LIMIT；模拟交易仅限价 / 市价；place_order 明确期权数量按张，价格两位小数。实际账户权限与券商受理仍以 API 返回为准。全程不提交真实账户测试订单。
