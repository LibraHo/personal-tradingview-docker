# 看盘交互调整 · 2026-10-29

- 搜索：回车、“查看”及 A 股名称搜索结果只切换当前图表。“＋”才加入当前分组；不自动加入精选。
- 日期：选择交易所当地日期后“前往”会直接补载附近数据，包括之前一周的指标预热数据。历史窗口不会混入今天的实时 K 线；“实时”回到最新图表。
- 左拖及“更早 K 线”继续分页补载。历史可查询跨度由 `HISTORY_LOOKBACK_DAYS` 控制，默认 3650 天；这仅是应用查询范围，实际数据取决于 OpenD 的历史覆盖、股票上市时间及账户权限，不保证提供十年分钟线。
- `CACHE_RETENTION_DAYS` 仍控制常规分钟线缓存。主动浏览的旧分钟线另保留 `BROWSED_CACHE_DAYS` 天（默认 7 天），之后随清理回收。重复请求同一已覆盖历史窗口在 24 小时内直接使用 SQLite；请求失败不会记录成功覆盖。
- 区间高低点：在可见 K 线极值处显示价格和短引线，无贯穿图表的价格线、不改变价格缩放范围；随拖动、缩放更新，可整体开关。
- EMA 与 MA（SMA）：新增时默认同时绘制 5、10、20，支持逗号分隔的自定义整数周期（1–2000，最多 12 条），并提供常用组合按钮。旧的 `{"period":20}` 单线配置继续有效；新多线为 `{"periods":[5,10,20]}`。颜色可逐线设置。
- MACD：快线、慢线、信号周期独立输入，默认 12/26/9。BBI、布林带、ATR、RSI、DMI、成交量均线也提供有名称的参数输入；高级 JSON 和 Python 指标入口保留。参数离开输入框后生效，沿用工作区和指标模板保存。

历史窗口新增只读接口：`GET /api/bars/window?symbol=US.SNDK&period=15m&mode=all&start=<秒级时间戳>&end=<秒级时间戳>`，单次最多 31 天；HTTPS 看盘入口通过既有登录保护的行情网关转发。
