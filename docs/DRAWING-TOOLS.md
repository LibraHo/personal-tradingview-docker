# 画线管理

工具栏支持水平线、趋势线和斐波那契回撤。水平线点击一次创建；趋势线和斐波那契分别点击两个锚点创建，可重复添加多个对象。

点击“选择 / 编辑”（默认模式），将鼠标移到主图中自己画的线附近。距离线条 10 像素内会显示手形，并提示“可选：对象名称”。点击后线条加粗，出现“已选”操作栏，并打开该对象的编辑器。点击空白处取消选中；按 Esc 取消绘制及选中。背景网格、十字光标、指标线不属于画线对象，点击不会打开画线编辑器。斐波那契任意一条比例线都代表同一组对象，删除时只删除该组。

也可直接打开“画线管理”，点击对象名称或“样式”编辑，无须在主图精确点击。每个对象均可单独显示、隐藏、删除，并设置颜色、1–4 像素线宽、实线、虚线或点线。水平线可修改价格；趋势线和斐波那契可修改两个锚点的价格，斐波那契还可反转锚点。

斐波那契编辑器的“每条比例线的颜色”中，0%、23.6%、38.2%、50%、61.8%、78.6%、100% 等当前比例线分别有颜色选择器。未单独设置的线继承“整组默认颜色”；单独设置后不受整组颜色修改影响，点击“恢复整组色”重新继承。比例颜色会保存，反转锚点时颜色仍跟随原比例。

“全部隐藏 / 全部显示”作用于当前股票、当前周期的全部画线，不删除对象，也不改变各对象独立的显隐设置。例如单独隐藏的趋势线，在整体恢复显示后仍保持隐藏。该开关不影响指标或挂档线。

画线的位置、样式和显隐状态随工作区保存，按股票及周期隔离。旧版画线会自动转换并保留原位置。“撤销”可恢复本次图表操作中的创建、修改、删除和整体显隐操作；切换股票或周期后清空撤销记录。

目前通过价格输入框调整锚点，不提供拖动锚点手柄。
