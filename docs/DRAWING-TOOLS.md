# 画线管理

工具栏支持水平线、趋势线和斐波那契回撤。水平线点击一次创建；趋势线和斐波那契分别点击两个锚点创建，可重复添加多个对象。

退出绘制模式后，在主图中点击线条附近可选中对象，通过出现的操作栏编辑样式或删除。斐波那契任意一条比例线都代表同一组对象，删除时只删除该组。

打开“画线管理”，每个对象均可单独显示、隐藏、删除，并设置颜色、1–4 像素线宽、实线、虚线或点线。水平线可修改价格；趋势线和斐波那契可修改两个锚点的价格，斐波那契还可反转锚点。

“全部隐藏 / 全部显示”作用于当前股票、当前周期的全部画线，不删除对象，也不改变各对象独立的显隐设置。例如单独隐藏的趋势线，在整体恢复显示后仍保持隐藏。该开关不影响指标或挂档线。

画线的位置、样式和显隐状态随工作区保存，按股票及周期隔离。旧版画线会自动转换并保留原位置。“撤销”可恢复本次图表操作中的创建、修改、删除和整体显隐操作；切换股票或周期后清空撤销记录。

目前通过价格输入框调整锚点，不提供拖动锚点手柄。
