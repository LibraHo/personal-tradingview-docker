# 按市场选择扫描名单

扫描页面严格跟随左侧 A 股/美股市场，扫描页不设置第二套市场选择。切换时重新读取该市场分组、清空上一个市场的结果。页面提交的 scope 必须含 market=CN 或 US；后台按市场解析全部关注列表、指定分组、关注板块、板块成分及显式代码。显式代码和板块属于其他市场时拒绝执行。

页面直接显示真实关注分组；板块目录支持行业、概念、其他板块，以及美股11行业ETF。选择“板块成分股”扫描全部去重成分，选择“板块指数 / ETF”扫描标的本身。扫描前显示后端解析的实际名单与数量。目录加载错误、过期或空名单会明确反馈。

新接口：POST /api/v1/scope-preview（需要 manage 权限），请求体为 scope，例如 {"kind":"groups","market":"US","groups":["US:group-id"]}，返回 rows、total、market；浏览器对应 /api/scanner/scope-preview，HTTPS经现有登录网关转发。此接口只读取名单，不执行行情扫描。GET /api/v1/watchlists?market=CN 仅返回 A 股分组；GET /api/v1/jobs 的摘要新增 market 字段。

新扫描结果仅展示 status=matched 且有效的命中，不列未命中；失败标的单列可展开原因与重试，不能把失败当作未命中。扫描开始后自动定位结果区。

兼容：旧 API 不传 scope.market 仍保持原跨市场语义；既有监控固定原方案，不会静默改写。旧跨市场监控在页面单独列出，可暂停并分别创建单市场监控。加载没有 market 的旧方案时，页面按当前市场创建副本，不覆盖旧方案。

验证：30项扫描/时间/持久化/API测试通过；浏览器验证市场切换、分组隔离、板块分页和搜索、指数/成分股范围区别，以及未命中/失败行不混入命中列表。
